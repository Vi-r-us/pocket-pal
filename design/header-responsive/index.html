Rules of the design
  • ≥ 900px — everything inline: month picker, “Copy month”, “Add Budget”, avatar.
  • 640–899px — subtitle hidden; “Copy month” becomes an icon-only button (with tooltip); primary action shortens to “Add”.
  • < 640px — top row keeps title + icon-only “+” + avatar. Page controls (month picker + overflow “⋯” menu) move to a second toolbar row under the header. Secondary actions like “Copy month” go inside the overflow menu.
  • The primary action never disappears — it only loses its label. Secondary actions degrade into the overflow menu.
  • Implementation mapping (Tailwind): subtitle already uses hidden md:block; add hidden md:inline on the “Copy month” label, sm:hidden on header-row controls, and render the toolbar row via the existing usePageHeaderControls slot with a sm:hidden wrapper. Pages without extra controls (Dashboard, Settings) never render the second row.
